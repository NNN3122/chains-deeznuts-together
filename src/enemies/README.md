# Enemies

Empty on purpose until Milestone 2. Every monster lives here as its own script (and later scene), with a shared `EnemyBase` for senses (sight cone, hearing radius, noise thresholds), states (idle / suspicious / search / hunt / attack / retreat) and how it grabs the chain.

Rules from `CLAUDE.md`: original designs only, server-simulated, reacts to player noise, and kills send the whole group back to the checkpoint.
